# Social Media Manager Client Portal

A web application for social media agencies to manage client relationships, content planning, post approvals, and deliverables.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Git and GitHub
- Vercel

## Project Purpose

Provide a centralized workspace where agencies and their clients can collaborate on social media content and track project deliverables.
